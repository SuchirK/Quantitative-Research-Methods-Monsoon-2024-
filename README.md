🎯 Course Overview

This repository contains discussion session related material, coding resources, and datasets from the Quantitative Research Methods course offered at Ashoka University for undergraduate Political Science students. The course introduces students with no programming background to quantitative tools for conducting empirical research.

Students learn the fundamentals of R programming, data management, statistical analysis, and research design, enabling them to apply computational methods to real-world social science questions.
